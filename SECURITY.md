# Security

Use the latest reviewed release and verify checksums. Do not run elevated. A local process already running as your account can access your own files; this app is not a security boundary against a compromised account or administrator.

Report safety bugs through this repository's GitHub security advisory feature if available, or file a minimal issue without private file paths, file contents, credentials or tokens. Include the OS, app version and a synthetic reproduction. Do not publish private cleanup reports.

There are no runtime third-party packages. Windows bundles a Python interpreter and PyInstaller support files under their respective licenses. Never weaken browser, OS, execution-policy or antivirus protection to run this app.
